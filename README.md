# myLib

Einfache Web-App zur Verwaltung der eigenen Bücher: Was besitze ich, was habe ich gelesen, was steht noch ungelesen im Regal?

## Starten

`index.html` im Browser öffnen. Die Daten werden lokal im Browser (localStorage) gespeichert; über „Exportieren“/„Importieren“ lassen sie sich als JSON sichern.
